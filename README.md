# Шинэ жилийн хүлээн авалтын ресторан хайх платформ

Иргэд, байгууллагууд ресторануудыг **дүүрэг, багтаамж, 1 хүнд ногдох бодит үнэ** болон үйлчилгээний нөхцөлөөр шүүж
харьцуулна. Ресторанууд цэсээ (PDF/зураг) байршуулахад Google Vertex AI (Gemini) багц бүрийг задалж, 1 хүний үнийг
автоматаар тооцоолж, менежер шалгаж баталгаажуулсны дараа нийтлэгдэнэ.

**Бүрэн локал** ажиллана: өгөгдлийн сан, файлууд таны компьютерийн `data/` хавтаст хадгалагдана. Postgres, Docker,
cloud бүртгэл хэрэггүй — зөвхөн Node.js. Интернэт зөвхөн AI-аар цэс уншихад л хэрэгтэй.

## Windows дээр ажиллуулах

1. **Node.js 20.9+** суулгана: https://nodejs.org (LTS). PowerShell-д `node -v` гэж шалгана.
2. Төслийн хавтаст орно:
   ```powershell
   cd C:\Users\NewTech\Desktop\restaurant
   git pull
   npm install
   ```
3. `.env.example`-ийг `.env.local` нэрээр хуулж, `VERTEX_API_KEY`-г бөглөнө:
   ```powershell
   copy .env.example .env.local
   notepad .env.local
   ```
4. Ажиллуулна:
   ```powershell
   npm run dev
   ```
   Браузерт http://localhost:3000 нээнэ.

Анх асаахад `data/` хавтас, өгөгдлийн сангийн хүснэгтүүд автоматаар үүснэ.

### Демо өгөгдөл (10 ресторан)
Өгөгдлийн сан хоосон бол `npm run dev` анх асахад 10 демо ресторан **автоматаар** орно
(`.env.local`-д `DEMO_DATA=false` бол орохгүй). Демо өгөгдлийг гараар шинэчлэх бол серверийг зогсоогоод (Ctrl+C):
```powershell
npm run seed
npm run dev
```
Янз бүрийн дүүрэг, багтаамж, үнэтэй 10 зохиомол ресторан, нийт 22 баталгаажсан багц орно.
Демо эзэмшигчээр нэвтрэх: утас `80000001` … `80000010`, нууц үг `demo12345` (баталгаажсан).
Дахин ажиллуулахад өмнөх демо өгөгдлийг шинэчилнэ (таны өөрийн бүртгэлд хамаарахгүй).

### Бүртгэл, утас баталгаажуулалт (verify.mn)
- Бүртгэл **утасны дугаараар**, нууц үгийг 2 удаа оруулна.
- Бүртгүүлсний дараа **[verify.mn](https://verify.mn)**-ээр баталгаажуулна: хэрэглэгч өөрийн дугаараас **144773**
  руу дэлгэцэнд гарсан 6 оронтой кодыг SMS-ээр илгээнэ (SMS 150₮, хэрэглэгч төлнө). Гар утсан дээр "SMS илгээх"
  товч SMS аппыг бэлэн текстээр нээнэ. Сервер 3 секунд тутам verify.mn-ээс төлөвийг шалгана.
- Баталгаажаагүй хэрэглэгч самбар, ресторан нэмэх, файл байршуулах, төлбөр хийх боломжгүй.
- `.env.local`-д `VERIFY_MN_API_KEY=vrf_...` тохируулна. Хоосон бол туршилтын горим (SMS-гүйгээр товчоор баталгаажна).
- Сайт https-ээр интернэтэд гарсан бол verify.mn callback (`/api/verify/callback`) автоматаар ашиглагдана.
- Өмнө имэйлээр бүртгүүлсэн хэрэглэгч имэйлээрээ нэвтэрч, баталгаажуулах хуудсанд утсаа нэмнэ.

### Туршиж үзэх
1. "Нэвтрэх" → "Шинээр бүртгүүлэх" → утас, нууц үг (2 удаа) → утсаа баталгаажуулах.
2. "Ресторан нэмэх" → мэдээллээ бөглөөд "Үргэлжлүүлэх" → 50,000₮ төлбөрийн хуудас → төлөх (туршилтын горим).
3. Заалны зураг нэмж, Шинэ жилийн цэсээ (PDF/PNG/JPG, 10MB хүртэл) байршуулна — AI багцуудыг гаргана.
4. Багц бүрийг шалгаж "Баталгаажуулах" дарна.
5. Нүүр хуудсанд шүүлтүүрээр хайна.

### Өгөгдлийг цэвэрлэх / нөөцлөх
- Бүх өгөгдөл `data/` хавтаст: `data/pgdata` (өгөгдлийн сан), `data/uploads` (зураг, цэс).
- Эхнээс нь эхлэх бол серверийг зогсоогоод `data` хавтсыг устгана.
- Нөөцлөх бол `data` хавтсыг хуулж авна.

### Олон ресторан, нийтлэлийн төлбөр
- Нэг хэрэглэгч хэдэн ч ресторан нэмж болно ("Миний ресторанууд" самбар).
- Ресторан бүрийг нийтлэх төлбөр **50,000₮** (`lib/constants.ts` → `LISTING_FEE`).
- Төлбөр төлөгдтөл ресторан хайлт болон нийтийн хуудсанд харагдахгүй; цэс, зургаа урьдчилан бэлдэж болно.
- Төлбөрийг **[Byl.mn](https://byl.mn)**-ээр авна (QPay, банкны апп, SocialPay, Pocket). `BYL_TOKEN`,
  `BYL_PROJECT_ID` тохируулаагүй бол туршилтын (demo) төлбөр ажиллана — товч дарахад төлөгдсөнд тооцогдоно.

#### Byl.mn тохируулах
1. https://byl.mn дээр бүртгүүлж project үүсгэнэ.
2. **Settings → API tokens** хэсгээс токен үүсгэж `.env.local`-д `BYL_TOKEN=...` гэж хийнэ.
3. Project settings дээрх дугаарыг `BYL_PROJECT_ID=...` гэж хийнэ.
4. Серверээ дахин асаана. Төлбөрийн хуудсанд "Byl-ээр 50,000₮ төлөх" товч гарна.

Төлбөр баталгаажих 2 зам:
- **Буцаж ирэхэд** — Byl төлбөрийн дараа `/api/byl/return` руу буцаана, сервер Byl-ээс checkout-ийн төлөвийг
  шалгаж рестораныг идэвхжүүлнэ. Локал (localhost) дээр ч ажиллана. Хэрэглэгч буцаж ирэлгүй хаасан бол төлбөрийн
  хуудсан дээрх **"Төлсөн бол — төлбөр шалгах"** товчоор баталгаажуулна.
- **Webhook** — сайт интернэтэд (https) гарсан үед Byl dashboard → Webhooks дээр
  `https://<домэйн>/api/byl/webhook` бүртгэж, Signing secret-ийг `BYL_WEBHOOK_SECRET`-д хийнэ.
  `Byl-Signature` гарын үсгийг HMAC-SHA256-аар шалгадаг.

Byl project **Test mode**-д байхад гүйлгээ бүр 100₮ байна. Жинхэнэ 50,000₮ авахын тулд Byl дээр бизнесээ
баталгаажуулж, багц идэвхжүүлж, үндсэн данс тохируулаад **Live mode** руу шилжинэ.
- Энэ өөрчлөлтөөс өмнө үүссэн ресторанууд болон демо ресторанууд идэвхтэй (төлөгдсөн) хэвээр үлдэнэ.

## Стек

| Бүрэлдэхүүн | Технологи |
| --- | --- |
| Frontend | Next.js 16 (App Router), Tailwind CSS 4 + shadcn маягийн UI |
| Өгөгдлийн сан | PGlite — процесс дотор ажилладаг Postgres (`data/pgdata`) |
| Файл хадгалалт | Локал хавтас `data/uploads`, `/uploads/...` замаар үзүүлнэ |
| Нэвтрэлт | Auth.js (NextAuth v5), имэйл + нууц үг (bcrypt) |
| AI | Google Cloud Vertex AI (Gemini) — `@google/genai` |

## Бүтэц

| Зам | Үүрэг |
| --- | --- |
| `app/page.tsx` | Нүүр хуудас: дүүрэг, 1 хүний төсвийн slider, багтаамж, нөхцөлийн шүүлтүүр |
| `app/restaurants/[id]` | Дэлгэрэнгүй: зургийн цомог, баталгаажсан багцууд, эх цэс харах, газрын зураг, залгах товч |
| `app/dashboard` | Эзэмшигчийн самбар: профайл, зураг, цэс байршуулах, AI үр дүнг шалгаж засах/баталгаажуулах |
| `app/api/upload` | Файлыг `data/uploads/<folder>/<user>/` хавтаст хадгална |
| `app/uploads/[...path]` | Хадгалсан файлуудыг үзүүлнэ |
| `app/api/menus/extract` | Цэсийг Gemini руу илгээж багцуудыг гаргана |
| `lib/db.ts` | PGlite холболт, анх ажиллахад `db/schema.sql`-г автоматаар ажиллуулна |
| `lib/vertex.ts` | Gemini дуудлага, `responseSchema`-тай JSON гаралт |
| `lib/pricing.ts` | AI гаралтыг цэвэрлэж 1 хүний үнийг дахин тооцох |

## Vertex AI тохиргоо (`.env.local`)

Аль нэгийг сонгоно:
- `VERTEX_API_KEY=...` — хамгийн хялбар.
- `VERTEX_CREDENTIALS=C:\path\to\vertex.json` + `VERTEX_PROJECT=...` — service account файлаар.

Gemini 1.5 загварууд Google дээр зогссон тул анхдагч загвар нь `gemini-2.5-flash`.
